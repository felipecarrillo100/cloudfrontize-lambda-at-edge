# Module 4: Production Workflows

In this final module, you'll learn how to bridge the gap between local development and production deployment using "Variable Baking".

## Exercises

### 4.1 The Baker (Production Build)
**Problem**: Your Lambda code needs to know the API endpoint URL, but that URL is different for Staging and Production.
**Goal**: Use a `.env` file and the `--bake` / `--output` flags to inject environment variables directly into your code before deployment.
